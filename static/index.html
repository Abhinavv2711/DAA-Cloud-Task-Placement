Algorithmic Optimization of Cloud Task Placement

Open Full HTML Report ↗

This project formalizes VM replica placement as an Integer Linear Program minimizing weighted client communication latency subject to CPU and RAM capacities.

min sum_{t in T} sum_{s in V} x_{t,s} * sum_{c in V} lambda(c, t) * dist(c, s)
subject to: sum_s x_{t,s} = 1, sum_t x_{t,s} * d_cpu(t) <= C_cpu(s), sum_t x_{t,s} * d_ram(t) <= C_ram(s)
